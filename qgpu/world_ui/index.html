WHAT IS NEW HERE?

The world stays resident.

The first launch uploads 80 words. Later launches upload programs and a start token, preserving world data across clear → advance → draw. The framebuffer is computed by the kernels.

WHAT DOES THIS VIEW SHOW?

Execution, with provenance.

Reference mode uses a CPU interpreter. Model mode uses a merged Qwen checkpoint. A reference recording is never labeled as a model run.
